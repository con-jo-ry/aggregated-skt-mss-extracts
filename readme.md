# Sanskrit Manuscript Extracts

This repository was created to provide researchers with an easily searchable collection of manuscript extracts, colophons, and metadata aggregated from various open-access cataloguing projects.

## 🗄️ Data Sources
The data in this repository is drawn from the following digital library projects. Please note the specific licensing terms associated with each dataset:

*   **[Cambridge University Digital Library](https://cudl.lib.cam.ac.uk/collections/sanskrit/1)** 
    *   License: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 
*   **[Bodleian Libraries, Oxford](https://github.com/bodleian/south-asian-mss)** 
    *   License unspecified 
*   **[Tokyo University Library](https://dzkimgs.l.u-tokyo.ac.jp/ut_skt_manuscripts/)** 
    *   License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0)
*   **[The Pandit Project](https://panditproject.org/)** 
    *   License: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)
*   **[TST Project](https://github.com/TST-Project/mss)** 
    *   License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
*   **TST Medical Texts** (via Charles Li) 
    *   Source: [TST-Project/cordier](https://github.com/TST-Project/cordier/blob/main/src/data/medical_mss.csv)
*   **[NGMCP Descriptive Catalogue](https://github.com/INDOLOGY/NGMCP-Descriptive-Catalogue)** 
    *   License: Unknown / Pending 

## ⚠️ Disclaimer
This repository is an aggregation of external datasets meant to facilitate broad text searching. The original content and source repositories should always be consulted for complete metadata and to verify that the extracted texts have not been erroneously rendered during the extraction process.
